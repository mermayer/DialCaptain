01 · Before you start

DialCaptain connects a Philips Hue Tap Dial RDM002 over Zigbee to an ESP32-C6 Zero with 8 MB flash. The ESP then sends commands over your Wi-Fi to Roon, a BluOS player or a WiiM. Your existing audio system continues to play the music.

  • A computer with Chrome or Edge, a USB data cable and the ESP. A charge-only cable is not enough. If you have trouble with a USB hub, use a direct computer port.
  • Your 2.4 GHz Wi-Fi name and password. The computer, ESP and player or Roon Server must be able to communicate on your home network. An isolated guest network is unsuitable.
  • For Roon: a running Roon Server and an existing playback zone. For BluOS or WiiM: a configured player; ideally create your desired presets in its app beforehand.
  • The Tap Dial remains battery powered. The ESP needs continuous USB power. The computer is only needed for USB setup; afterwards a suitable USB power supply is enough.

No Hue Bridge, RoonPilot, Home Assistant or extra computer service is required. A Tap Dial belongs to one Zigbee network; it cannot be paired with a Hue Bridge and DialCaptain simultaneously.

Development preview 0.2.0-dev.8. Existing control has been tested. Complete first pairing of a new remote and restoring after a real factory flash still need separate hardware acceptance. This preview is not a stable release.

02 · Install over USB

The Web Installer writes firmware over USB. The same assistant then guides you through Wi-Fi, server selection or restoration. You do not need a development environment or speculative driver downloads.

  1. Back up an existing device: If the ESP already runs DialCaptain with your settings, export a backup file first. A complete erase removes Wi-Fi, profiles and Tap Dial pairing. A factory-new ESP has nothing to back up yet.
  2. Connect the ESP directly: Plug a USB data cable into the computer and ESP32-C6. Close serial monitors and other browser tabs that have opened this device.
  3. Open the installer: Use the button below in Chrome or Edge on your computer. A hosted page needs HTTPS; the local preview on localhost also works. Do not open the HTML file by double-clicking it.
Open USB Web Installer
  1. Choose “Install / update firmware”. The browser opens its USB device chooser. Select your connected ESP and click Connect. Its name is often USB JTAG/serial debug unit or similar. COM… on Windows and cu.usbmodem… on macOS are port names and may differ.
  2. Select “Install DialCaptain” in the installer. “Erase device” means a complete erase. Use it for a deliberate clean installation; first check your backup if the device is already configured. An update without erasing is only intended for a matching existing flash layout.
  3. Confirm installation and wait. Do not disconnect the cable or close the browser. Wait for the completion message, not merely a progress bar.
  4. Close the installer dialog. This releases the serial connection. If the firmware does not start after flashing, release BOOT and press RESET once. Wait for the USB device to reappear.
  5. Choose “Start setup” below, select the ESP again and connect. Now choose “Set up as new” or “Restore backup”. Restoration can start immediately, before Wi-Fi has been configured.
Wrong chip? This installer is for ESP32-C6 only. If it reports another ESP, stop and select the correct board. Unlike the RoonPilot display, this board has no second Companion processor. Turning the USB-C plug does not select another ESP.

No device listed or connection failing?

  1. Try another USB data cable and a direct USB port. Check that Chrome or Edge is allowed to show the USB chooser and no other program owns the serial port.
  2. For empty flash, or if automatic entry fails: hold BOOT, briefly press and release RESET, then release BOOT. Select the newly detected port again in the browser. This enters download mode without erasing settings.
  3. After successful flashing, leave BOOT released; press RESET once if necessary and start USB setup again.

This sequence follows the Waveshare C6 Zero instructions. It differs from holding BOOT for three seconds when DialCaptain firmware is already running.

03 · Wi-Fi & server

Set up as new

  1. After “Start setup”, connect the ESP and choose Set up as new.
  2. Select your 2.4 GHz Wi-Fi from the list. “Search again” refreshes it; enter the network name manually for a hidden network. Enter the password only in its password field.
  3. Click “Test connection and save”. The ESP checks connectivity and only saves the new credentials after success. This can take about 20 seconds. If it fails, follow the displayed explanation; a failed attempt does not replace stored credentials.
  4. If the ESP is already connected, choose “Use connected Wi-Fi”.

If you want to use Roon

  1. Select the discovered Roon Server and click “Select server and save”.
  2. If it is missing, check that Roon Server is running. Search again or enter its IP/hostname and API port under “Add a server by its address”. The default is 9330. “Check server” verifies its identity before saving.
  3. In Roon, open Settings → Extensions and enable DialCaptain. Use “Check connection” in the assistant to refresh its status. Select your zone afterwards through the extension’s settings gear.

BluOS and WiiM do not require Roon approval. Once Wi-Fi is connected, choose “Activate web configuration” → “Open web configuration” in the additional section; skip the Roon Server selection.

Your computer stays connected to its normal network. DialCaptain does not create a setup Wi-Fi hotspot. USB sends the Wi-Fi details directly to the ESP. The later device webpage uses the address assigned by your router, not 192.168.4.1.

04 · Pair the Tap Dial

First pairing works without an already assigned remote. After configuring Wi-Fi, activate and open web configuration from the USB assistant. Alternatively hold BOOT on the running ESP for three seconds and open its known IP address.

  1. In “Pair Philips Hue Tap Dial”, choose “Pair your first Tap Dial”. Joining is open for three minutes.
  2. Place the new Tap Dial near the ESP. Hold button 1, marked with one dot, for about three seconds until its LED blinks.
  3. The browser shows Searching → Checking → Setting up → Done. During setup, press a button briefly from time to time to keep the battery-powered remote awake. These presses do not send music commands while pairing is active.
  4. The assignment is only saved at Done. Now choose your audio mode and button mappings.

Previously paired with a Hue Bridge or another ESP?

Reset only the Tap Dial itself: hold the SETUP button on its back for more than ten seconds. This removes its former Zigbee association. Then hold button 1 for about three seconds while the joining window is open. The ESP does not need a factory reset.

Set up again or replace

“Set up the current Tap Dial again” repairs setup for the same remote; normally a brief press to wake it is enough. “Pair a different Tap Dial” asks for confirmation and only replaces the existing assignment after complete success. One ESP uses one assigned Tap Dial. Cancellation or expiry does not erase your current assignment or audio settings.

References: Philips Hue manual and product FAQ.

05 · Roon control

  1. On the device webpage, select Control mode → Roon and save if another mode is active.
  2. In Roon, open Settings → Extensions → DialCaptain, enable it and open its settings gear.
  3. Choose Language / Sprache. It is independent of the Roon app language.
  4. Select your desired Roon zone from the list.
  5. Set Dial sensitivity and Steps per click separately. Choose 1–4 native Roon steps. For example, with an output using 0.5 dB per native step, two steps give 1 dB per click. The selected Roon volume provider determines the unit and resolution.
  6. Assign each of the four buttons a short and long action, such as Play/Pause, next/previous track, mute or a favourite.
  7. For each of the three favourites, choose Roon playlist or Roon radio station, then select the entry from the list. Radio entries come from My Live Radio. Use the next/previous pages for longer lists; there is no need to type names.
  8. Save. At a low listening level, try one command first. The extension status line also shows the Tap Dial battery reading after its first report; until then it says that no reading is available.

The screenshot shows an example zone with two native Roon steps per click. An RME Bridge can act as the volume provider in Roon; DialCaptain does not need its own RME or IR connection. A fixed-volume output may not be controllable with the ring.

06 · BluOS control

  1. Open the device webpage and select Control mode → BluOS control.
  2. Choose your player from network discovery. It shows names, models and addresses. If the list is empty, enter its IP address or hostname manually; the default port is 11000. Use “Check player & load presets” to confirm the device. Discovery and checking do not start playback.
  3. Select three presets already stored on the player. Set up desired stations, playlists or other content as BluOS presets first; DialCaptain does not manage their contents.
  4. Assign short and long actions: Play/Pause, play, pause, previous/next, toggle mute, stop, preset 1–3 or no action. The player’s current source determines which transport actions are supported.
  5. Choose sensitivity and 0.5 / 1 / 2 dB per click. Player limits and actual resolution still apply. A fixed output level is respected.
  6. Save settings. Saving activates your selection. The Roon and WiiM profiles remain stored.

Volume commands address the chosen BluOS player without explicitly adjusting its other group members. Failed or old commands are not replayed later. Tested examples do not imply that every BluOS model, source and grouping combination has been tested.

07 · WiiM control

  1. In WiiM Home, save your chosen content as presets. Depending on the service, a preset may start radio, a playlist, an album or other content.
  2. Open the device webpage and select Control mode → WiiM control.
  3. Select your discovered WiiM or enter its IP address. The local HTTPS API normally uses port 443. “Check player & load presets” verifies the device and reads up to twelve presets.
  4. Choose three favourites from those presets and assign short/long button actions. Previous/next only work with sources that support them.
  5. If you want to control the WiiM’s own volume, enable “Control WiiM volume with the dial”. It is initially disabled for a new profile. Set 1 / 2 / 5 percentage points per click and sensitivity independently.
  6. Save settings. Other mode profiles stay stored.
Direct WiiM volume is not the volume of an external DAC. For a Roon zone using an RME volume provider, use Roon mode. DialCaptain does not change the WiiM output type automatically; configure a fixed/variable output yourself in WiiM Home as needed.

DialCaptain does not browse entire streaming-service catalogues; presets are managed in WiiM Home. According to the WiiM API, mute may also affect members of an existing WiiM group. DialCaptain does not create groups. Integration has been tested with a WiiM Ultra; other models and sources may behave differently.

08 · Web configuration

The web server is only needed for configuration and normally stays closed. The ESP still retains its network address.

Entry pointHow it works
Tap DialBy default, hold button 4 for at least eight seconds and release. Repeat this extra-long press to close the web server. It does not trigger the normal short/long action. Choose another button or disable just this shortcut in web configuration.
ESP BOOT buttonHold for three seconds on the running ESP to toggle the web server. Do not press RESET.
USB assistantConnect the ESP; after the Wi-Fi step choose Activate web configuration, then Open web configuration. This works before your very first Tap Dial pairing.

The RGB LED gently blinks amber while web configuration is active. In a normal browser open the address shown by the assistant, for example http://192.168.1.50/. That is only an example; your router assigns the actual address. Your phone or computer must be able to reach the ESP on your home network.

The page shows the remaining time. Extend by 10 minutes gives you more time; Close now ends it immediately. After ten minutes without interaction the HTTP service stops; background status polling does not extend the session. Zigbee, Wi-Fi and audio control keep running. Closing the web server does not put the ESP into deep sleep.

The device page offers German/English, mode selection, pairing and file backup. Roon’s button actions and favourites are still configured through the extension settings gear.

09 · Backup & updates

Export settings

Under “Back up and restore” on the device page or USB assistant choose “Export settings”. Your browser downloads a JSON file to your computer. It includes the saved state, not unsaved form edits.

  • Wi-Fi credentials, active mode and web-access shortcut.
  • Roon Server, authorization, zone, language, buttons, favourites, sensitivity and steps.
  • Complete BluOS and WiiM profiles, including inactive modes.
  • The selected Tap Dial and stored Zigbee network/pairing information for the same ESP.

No extra password or cloud account is required. The file contains Wi-Fi and pairing keys: keep it private on your computer and do not attach it to a public bug report. Importing it onto a different ESP is not supported.

Restore directly after a clean USB installation

  1. Close the installer dialog after flashing.
  2. Choose Start setup, connect the same ESP and choose Restore backup. Wi-Fi does not have to be configured yet.
  3. Select the JSON file and review the summary. Uploading and checking it does not yet change active settings.
  4. Confirm replacement and choose Prepare restoration.
  5. Use the separate Restart now button to apply it. Until then, other settings and audio-button commands are blocked. Keep power connected while restoration is being applied.
  6. Reconnect USB if necessary, or open the restored network address. Wake a sleeping Tap Dial with a brief button press.

Future firmware updates

DialCaptain has no dedicated OTA updater. Updates use the USB Web Installer. Export before a complete erase. Without “Erase device”, a compatible application/layout update may preserve settings; a clean installation removes them. A backup file is therefore the normal recovery path.

Import validates the device, file format, checksum and Zigbee compatibility and uses a resumable application state. Do not make a factory reset your first response to a restore error. Complete restoration after a real factory flash has not yet received physical acceptance in this development version.

10 · Troubleshooting

ObservationNext step
No USB device / connection failsCheck a data cable, direct USB port and Chrome/Edge. Close serial monitors. For a factory-new/empty ESP, use the BOOT/RESET sequence above.
No setup after flashingClose the installer dialog, release BOOT, press RESET once, then select “Start setup” and the newly detected ESP.
Wi-Fi connection failsCheck 2.4 GHz, the exact network name and password. Avoid isolated guest Wi-Fi. Retry over USB; a failed connection test does not replace saved credentials.
Device page does not loadActivate the temporary web server first. Use the actual ESP address shown by the assistant/router and check reachability on the same network.
Roon Server or player missingCheck that it is running. Network segmentation can filter discovery. Search again or check a manual address. Use 9330 for Roon, 11000 for BluOS and normally 443 for WiiM.
Tap Dial does not respondCheck its battery, assignment and active mode. Wake it briefly. Try “Set up again”. Deliberately reset an already elsewhere-paired remote when required, not the ESP.
Playback works, volume does notCheck the output in Roon. Respect fixed volume in BluOS; enable WiiM’s separate dial option and check its output configuration. Direct WiiM control does not adjust an external RME DAC.
Restore is rejectedUse the correct format from the same ESP. Preserve the error text. Do not import another coordinator’s pairing data or erase settings hastily.

When reporting a problem, include the firmware version, mode, board model, failing step and exact error text. The USB installer console can help diagnose it. Do not copy Wi-Fi passwords or backup files into public reports.
