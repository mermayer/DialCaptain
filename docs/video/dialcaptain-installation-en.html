  1. Install and set up DialCaptain

    Welcome to Dial Captain. This guide takes you through installation and setup, one step at a time. We will connect the small controller to Wi-Fi, pair a Philips Hue Tap Dial, and configure Roon, Blu OS or WiiM. You do not need programming knowledge. Pause whenever you want to follow a step at your own pace. The chapters below the video let you jump straight to the mode you want.

  2. One dial. Three audio control modes.

    The Tap Dial sends button presses and dial movements to the ESP over Zigbee. The ESP translates them into Wi-Fi control commands. Exactly one mode is active at a time: Roon, Blu OS or WiiM. Settings for the other modes are retained. Dial Captain does not stream music or act as a speaker. You do not need a Hue Bridge, Roon Pilot or an additional computer service. Roon mode still requires your existing Roon Server.

  3. Prepare the correct hardware

    Prepare an ESP32 C6 Zero with eight megabytes of flash, a Philips Hue Tap Dial model RDM002, and a USB data cable. Check the exact board name. A similar-looking ESP32 S3 is not the same device. The Tap Dial runs on its battery. The ESP, however, needs continuous USB power. You will also need the name and password of your 2.4 gigahertz Wi-Fi network. A charge-only USB cable cannot transfer firmware.

  4. Chrome or Edge on a computer

    Open Chrome or Edge on your computer. This guide uses the tested USB workflow in those browsers; it does not cover installation on a phone. Close serial monitors and other browser tabs already using the ESP. Your computer, ESP and player must be able to reach each other on the home network. An isolated guest network is unsuitable. Later, you can open the device configuration from a phone on that network.

  5. New board or existing setup?

    A factory-new ESP has nothing to back up. If Dial Captain is already configured, first export its settings from the device webpage or USB assistant. A complete erase also removes Wi-Fi, button assignments and Tap Dial pairing. The backup belongs to that particular ESP and contains private credentials. Keep it on your computer. We will cover restoration later. A firmware update is no reason to reset the Tap Dial as a precaution.

  6. Start on the DialCaptain project page

    Start on the Dial Captain project website hosted on GitHub. It provides the guide and the entry for USB installation. At the time of this video, a public firmware release and online installer have not yet been approved. The following recordings show the existing local development installer so you can learn the workflow. A status page is not an installation error. Once the public installer is released, start from the project page. This video does not publish firmware itself.

  7. Connect only the intended ESP

    Connect only the intended ESP32 C6 to your computer by USB. Temporarily disconnect other ESP boards from the computer to avoid selecting the wrong one. If you have trouble, use a direct USB port rather than a hub. Locate the small BOOT and RESET buttons on your board. Their positions can vary between board versions. The illustration explains their functions and is not a scale drawing of the board layout.

  8. If the new board cannot be reached

    The first installation may require manual download mode. Leave the ESP connected by USB. Hold BOOT. While holding it, briefly press and release RESET. Then release BOOT. Open the browser USB selection again. Do not press either button while firmware is being written. Unlike the round Roon Pilot, this separate C6 board does not select a second processor by reversing the USB connector.

  9. Select the connected ESP

    In the local installer, select Install or update firmware. The browser opens its own device picker. Click the connected ESP and then Connect. It is often called USB JTAG or Serial Debug Unit. On Windows it may include a COM number. On macOS the name looks different and there is no Windows COM number. Names and numbers in this video are examples. If unsure, cancel and unplug the board to see which entry disappears.

  10. Choose Install DialCaptain in the installer

    After USB access is granted, the installation dialog appears. Choose Install Dial Captain. The name and displayed version must match your intended device. The installer is configured for the ESP32 C6. If another chip is reported or the board is unsupported, do not install unrelated firmware. Close the dialog and check the board, cable and selected USB port first. These installer dialogs may use English labels even when the surrounding page is German.

  11. Erase device means a complete erase

    For a clean installation, select Erase device, then Next. This removes existing data on the ESP, including saved Wi-Fi and Tap Dial pairing data. On a new board, it gives you a clean starting point. On an existing device, make sure you already have your backup file. An appropriate update without erasing can retain settings, but that is not a blanket guarantee for every firmware version and storage layout.

  12. Confirm with Install only when ready

    Read the final confirmation. Check once more that you intend to install Dial Captain on the correct C6 board. Only then click Install. Keep the USB cable connected throughout. Do not close the browser window or let the computer sleep. The progress shown in the video is shortened. You do not need to select individual files, enter memory addresses or install a development environment.

  13. Wait for erasing, writing and completion

    The installer prepares the board, erases storage if requested, and writes the firmware. The percentage can pause for a while. Wait for the explicit completion message. Reaching one hundred percent alone is not a reason to unplug. If the browser reports an error, record its exact text. Check the cable, direct USB connection and download mode before trying again. A video animation is, of course, not proof of a physical flashing test.

  14. Close the installer and start the firmware

    After successful completion, close the installation dialog. This releases the USB port for the next step. BOOT must now be released. If the board remains in download mode, briefly press RESET without holding BOOT. Wait a moment for the new firmware to start. The USB entry may disappear briefly and return. You do not need a separate application to configure Wi-Fi first.

  15. Select Start setup and reconnect

    Below the installer, click Start setup. Select the same ESP again in the USB picker and confirm. This is intentional: the installer used the port first, and now the setup assistant talks to the running firmware. If the port is busy, check whether the old installation dialog or a serial monitor is still open. The ESP does not need Wi-Fi yet, and you do not need to select a special setup network on your computer.

  16. Set up as new or restore a backup

    You now have two choices. For the first setup, choose Set up as new. If you have a backup from this exact ESP, you can instead choose Restore backup, even before Wi-Fi is configured. We will follow new setup first and cover restoration in its own chapter. A backup from another ESP is not a way to clone a second controller or pair one Tap Dial to two devices at the same time.

  17. Select your 2.4 GHz Wi-Fi network

    The assistant searches for Wi-Fi networks within range of the ESP. Open the list and choose your own 2.4 gigahertz network. Do not confuse it with a neighbour’s similar name or an isolated guest network. If yours is missing, scan again or enter its exact name manually. Your computer stays on its normal home network. Dial Captain does not create a setup hotspot for this workflow. The details are sent directly to the ESP over USB.

  18. Enter the password, then test the connection

    Enter your Wi-Fi password. This video uses fictional example details only. If needed, use Show to check for typing mistakes, then hide the password again. Select Test connection and save. New credentials are saved only after a successful connection. If the test fails, check the name, password and 2.4 gigahertz network. An unsuccessful attempt does not replace previously saved credentials.

  19. Wi-Fi connected: choose your next path

    Once Wi-Fi is connected, you can choose a Roon Server or open the device webpage directly. Blu OS and WiiM need no approval in Roon, so you can skip server selection. Note the device address shown by the assistant. Your router assigns it, and yours will differ from the video example. The address 192 dot 168 dot 4 dot 1 used in some other device guides is not used for this USB setup.

  20. Enable and open web configuration

    In the assistant, choose Enable web configuration. Once the service is ready, Open web configuration appears. Click it. The new tab shows a webpage served by the ESP, not a cloud configuration service. Your computer or phone must be able to reach that ESP on the home network. While the web server is active, the board’s RGB LED gently blinks amber. This works even before any Tap Dial is paired or any Roon Server selected.

  21. Choose Pair your first Tap Dial

    Find the Pair Philips Hue Tap Dial section. A new device has no controller assigned yet. Click Pair your first Tap Dial. Discovery is now open for three minutes. Place the intended Tap Dial near the ESP. You do not need a Hue Bridge or an already paired controller for this. Simply powering the ESP does not leave pairing permanently open. You deliberately start discovery here.

  22. Hold button 1 for about three seconds

    On a new Tap Dial, hold the button marked with one dot for about three seconds until its LED blinks. The browser should progress from Searching to Checking and Setting up. During setup, briefly press a button occasionally to keep the battery-powered controller awake. These presses do not send music commands while pairing is in progress. If your Tap Dial already belongs to a Hue Bridge or another ESP, follow the next step first.

  23. Reset only the Tap Dial when needed

    A Tap Dial can belong to only one Zigbee network. If it was paired with a Hue Bridge or another ESP, reset that controller only: hold SETUP on its back for more than ten seconds. This removes its old pairing. Then, with discovery open, use button one again. Do not factory-reset the ESP for this. When restoring a suitable backup to the same ESP, resetting the controller is not the normal procedure.

  24. Wait for Done

    Wait until the page says Done. Only then is the assignment saved. The progress states shown demonstrate the interface. Full first pairing of a new controller has not yet completed physical acceptance in this development version. Use Set up again for the existing controller. A different Tap Dial replaces it only after successful, confirmed setup. Cancelling or timing out does not delete the previous assignment. Check the battery and keep the controller awake before resetting anything.

  25. Select Roon, BluOS or WiiM

    Under Mode, choose what the Tap Dial should control. Roon controls a zone on your Roon Server. Blu OS controls a Blu OS player directly. WiiM controls a WiiM directly through its local interface. Only one mode runs at a time. Saving activates your choice without deleting the other profiles. The next chapters cover all three paths. You only need to configure the one you intend to use now.

  26. Choose the Roon Server in the USB assistant

    For Roon, select Roon mode on the device webpage and save. In the USB assistant, open Roon Server selection. Choose your running server from the list and save it. If discovery is empty, first check that the server is running and reachable on your network. Alternatively, check its address with the usual API port 9330. Avoid selecting a second server by mistake. A different server needs its own approval and a new zone selection.

  27. Roon → Settings → Extensions

    Now open Roon, then Settings and Extensions. Find Dial Captain and click Enable. Next, open the extension’s settings cog. This schematic view explains the path; the exact arrangement can vary with your Roon version. Use Check connection in the USB assistant to see whether approval has arrived. Configure Roon volume and buttons in that settings cog, rather than on the general device webpage.

  28. Set your zone, language and steps

    Choose your Roon zone. Set the extension language to German or English as needed; it is independent of the Roon app language. Sensitivity and Steps per click are separate settings. You can select one to four native Roon steps. With an output using half a decibel per step, two steps give one decibel per click. Each of the four buttons can have a short and long action, such as play, pause, next, previous or mute.

  29. Choose playlists and radio from lists

    For each of the three favourites, first choose Roon playlist or Roon radio station, then select an item from the list. Radio stations come from My Live Radio. You can page through longer lists. Assign the favourites to buttons and save everything. At low listening volume, test one button press and a small dial movement first. After the Tap Dial reports back, its battery level can also appear in the status line. A fixed Roon output may not support volume changes.

  30. Choose a BluOS player on the network

    For a Blu OS player, choose Blu OS control on the device webpage. Discovery shows reachable devices with their name, model and address. Deliberately select your player. If it is missing, enter the address manually; the usual port is 11000. Check player and load presets confirms the target and loads its saved presets. This does not start music. The mode is for Blu OS generally, not just one particular NODE model.

  31. Assign presets and volume steps

    First save your radio stations or playlists as presets in the Blu OS app. Choose three of those as favourites here. Assign short and long button actions, then select sensitivity and half, one or two decibels per click. Save the settings. With a fixed output level, the ring has no effect. Next and previous depend on the current source. Dial Captain does not maintain its own streaming library, and its volume commands do not explicitly adjust other group members.

  32. Choose your WiiM and its presets

    For WiiM, first save the desired content as presets in WiiM Home. On the device webpage, choose WiiM control and select the discovered player. Alternatively enter its address; the local HTTPS interface normally uses port 443. Check the player and load its presets. Up to twelve entries can be shown. Choose three as your favourites and assign them to short or long presses. Supported content and track commands depend on the service and source.

  33. Explicitly enable the ring for WiiM

    On a new profile, ring control of the WiiM’s own volume starts disabled. Enable it only if that is the volume you intend to control. Choose one, two or five percentage points per click, then save. This does not directly adjust an external DAC. For a Roon zone using an RME volume provider, use Roon mode. The output configuration in WiiM Home is not changed automatically. Also note that WiiM mute commands can affect members of an existing group.

  34. Hold for eight seconds, release, configure

    In daily use the web server is normally closed. By default, hold Tap Dial button four for at least eight seconds, then release. The amber LED indicates that configuration is available. The same extra-long press closes it again without triggering an ordinary button action. Alternatively hold BOOT on the running ESP for three seconds, without pressing RESET, or open access over USB. After ten minutes without interaction, the webpage closes. Extend gives you another ten minutes. Audio control continues.

  35. Save a backup file on your computer

    Open Backup and restore, then choose Export settings. Your browser saves a JSON file on your computer. It includes Wi-Fi, Roon approval and zone, buttons and favourites, all Blu OS and WiiM profiles, plus Tap Dial and Zigbee data for the same ESP. Unsaved form edits are not exported. No extra password or cloud account is required. Because the file contains credentials, do not attach it to public bug reports. Export it before a complete USB reinstallation.

  36. Restore even before Wi-Fi setup

    After reinstalling, close the installer, start USB setup and choose Restore backup. Use the file from this exact ESP. Check the summary. Explicit confirmation and preparation save the restore request. Then choose Restart now and keep power connected. Reconnect USB afterwards if needed. Full restoration after a real factory flash has not yet completed physical acceptance in this development version. The film explains the workflow available in the assistant, rather than claiming release approval.

  37. The computer can be switched off afterwards

    After setup, you no longer need the computer. Power the ESP from a suitable USB supply and leave it connected to Wi-Fi. The Tap Dial continues to use its battery. Roon still needs a running Roon Server; Blu OS and WiiM are controlled directly. A closed configuration webpage is normal and does not mean the controller is offline. There is no dedicated over-the-air updater. Future firmware updates use USB again, so keep your backup file.

  38. Check the cause before resetting everything

    No USB device: check the data cable, direct port, closed monitors and BOOT with RESET. No Wi-Fi: check the name, password and 2.4 gigahertz network. No device webpage: enable the temporary server first and use the actual IP address. No music control: check the active mode, player or Roon zone, and saved buttons. No volume control: check for fixed output and the WiiM ring option. Record the version, step and exact message when reporting a fault. Factory reset is not the first troubleshooting step.

  39. Your dial is ready for your music

    That completes the Dial Captain installation and setup guide. You now know how USB selection and download mode work, how to configure Wi-Fi, pair the Tap Dial and choose your audio control mode. Use the chapters to revisit individual steps. The large project-page button below the video leads to the current guide and release status. Enjoy using your own music controller.
